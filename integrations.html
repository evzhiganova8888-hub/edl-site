Как работает OAuth-флоу подключения

  1. Выбор источника

    В кабинете EDL OS жмёте «Подключить amoCRM».

  2. Authorize в провайдере

    Открывается окно amoCRM/Google. Подтверждаете доступ.

  3. Hub хранит токен

    Refresh-token в зашифрованном Vault. Модель его не видит.

  4. Tools доступны в агенте

    Claude/Cursor получают список tools через MCP.
