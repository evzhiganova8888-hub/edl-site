# Чекап Plus v2.0 — что ещё предстоит сделать

Этот документ — TODO по ТЗ «EDL OS · Чекап Плюс v2.0» от 21.05.2026,
которое не успело войти в текущий PR. ТЗ описывает 4-недельный roadmap
(Спринты 1–4: 22.05 → 15.06), поэтому за одну сессию вошла только часть.

## В этом PR (готово)

- Тексты гарантии возврата приведены к строгой условной формулировке:
  возврат при двух условиях — (а) ответы прошли рубрику качества,
  (б) ни одну рекомендацию нельзя реализовать. Контекст для
  реалистичности рекомендаций собирается во время Чекапа.
- Видео-разбор Plus подписан как «команда EDL OS», не персонально
  Екатериной. ИП «Жиганова Екатерина Викторовна» — оставлено как
  юридический идентификатор оператора.
- Промокод-engine `core/coupon_engine.py` с жёстким 24-часовым TTL.
  Двойная проверка времени на каждом клиентском пути защищает от окна
  гонки. Celery-task `expire_coupons` каждые 15 минут синхронизирует
  колонку `status`.
- Миграция `0014_coupons.py` (coupons + coupon_usages).
- Команды клиента: `/diagnostika` (проверка купона).
- Админ-команды: `/issue_coupon`, `/coupon_info`, `/confirm_payment`.
- Регрессионные тесты: `test_coupon_engine.py`,
  `test_refund_language.py`, `test_video_attribution.py`.
