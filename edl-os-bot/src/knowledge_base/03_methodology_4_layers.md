# Методология EDL OS · 4 слоя

EDL OS — операционная система собственника бизнеса, состоящая из 4 слоёв.
Каждый слой имеет диагностику, ключевые цифры и набор инструментов.

## Слой 1 · Стратегия

**Вопрос слоя:** куда вы идёте через 3 года и какие 3 ставки делаете
прямо сейчас?

**Маркер-слова в разговоре:** «направление», «фокус года», «что не делаем»,
«ключевые ставки», «горизонт», «миссия».

**Ключевые артефакты:**
- Видение через 3 года (1 страница)
- 3 главные ставки этого года (с цифрами успеха)
- Список «что мы НЕ делаем» (это сильнее, чем список «что делаем»)

**Типичные провалы:** размытое позиционирование, конкуренция со всеми по
всему, отсутствие явных «не-целей».

## Слой 2 · Воронка

**Вопрос слоя:** где живёт ваша воронка, какие конверсии на каждом этапе
и кто закрывает?

**Маркер-слова:** «лиды», «конверсия из демо в договор», «средний цикл
сделки», «cold», «warm», «hot», «pipeline» (внутреннее), «CAC».

**Ключевые артефакты:**
- Воронка по стадиям с конверсиями
- Средний цикл сделки и средний чек по сегменту
- Owner каждого этапа
- Источники лидов с CAC

**Типичные провалы:** воронка в голове основателя, конверсии не считаются,
закрытие сделок — только на собственнике (bottleneck).

## Слой 3 · Операционка

**Вопрос слоя:** где узкие места в загрузке команды и в маржинальности
проектов?

**Маркер-слова:** «загрузка», «маржа по проекту», «utilization», «узкое
горлышко», «retainer», «billable» (для services), «оборачиваемость»
(для wholesale).

**Ключевые артефакты:**
- Загрузка ключевых ролей в часах
- Маржа по проектам / клиентам / категориям
- Карта узких мест
- 3 действия на ближайшую неделю

**Типичные провалы:** проектная маржа не считается, перегруз 1–2 человек,
бесконечные «горячие» проекты блокируют развитие.

## Слой 4 · Деньги

**Вопрос слоя:** хватает ли cash, какая реальная маржа после налогов,
готовы ли вы к НДС-2026 / антидроблению?

**Маркер-слова:** «cash», «маржа», «оборотка», «налог», «НДС», «УСН»,
«антидробление», «дроблен», «упрощёнка», «общая система».

**Ключевые артефакты:**
- Cash flow на 3 месяца вперёд
- EBITDA / маржа с учётом налогов
- Налоговая карта (НДС-впервые / антидробление / переход на ОСНО)
- 90-дневный план денежных решений

**Типичные провалы:** cash в голове, EBITDA не учитывает НДС-эффект,
структура «несколько ИП» без подготовки к антидроблению.
