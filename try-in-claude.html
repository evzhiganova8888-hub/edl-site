Откройте EDL OS прямо в Claude / Cursor

Подключите наш MCP-сервер за 3 шага — и тот же Mini-Чекап и ИИ-консультант появятся внутри вашего рабочего AI-помощника. Один контекст, один диалог, нативное переключение.

🏗️ Статус: MCP-сервер на этапе тестового запуска. Если хотите получить ранний доступ — оставьте email на этой странице или напишите в Telegram.

1

Установите Claude Desktop

Скачайте официальный десктоп-клиент. Если у вас уже есть — переходите к шагу 2. MCP работает и в Cursor / ChatGPT Desktop / Gemini CLI — см. список клиентов ниже.

claude.ai/download →
2

Добавьте EDL OS как MCP-сервер

В Claude Desktop: Settings → Developer → Edit Config. Добавьте блок ниже. URL можно скопировать одной кнопкой.

https://mcp.edl-os.com/v1
← Сдвиньте, чтобы увидеть полный URL →
Имя:
EDL OS
Тип:
SSE / HTTP
Auth:
OAuth 2.1 (автоматически)
3

Авторизуйтесь через OAuth

Перезапустите Claude Desktop. При первом обращении к EDL-инструменту откроется браузер для одноразового OAuth-логина. Вернётесь в Claude — авторизация уже принята. Email будем спрашивать только при отправке итогового PDF.

Можно ли отозвать доступ?

Да, в один клик. Команда /revoke в Telegram-боте или кнопка «Отозвать доступ» в личном кабинете отзывает все OAuth-токены за секунды. История диалогов удаляется по запросу.
