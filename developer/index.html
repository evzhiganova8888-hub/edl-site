Исходники mcp-server-core · MIT.

Архитектура: Open Core

EDL OS строится по принципу Open Core. Транспорт (JSON-RPC поверх SSE/HTTP), схемы tools, OAuth-флоу, коннекторы 1С/amoCRM и аудит-логи — открыты под MIT. Бизнес-логика (промпты Founder OS Score, бенчмарки 100+ компаний, методология 4 слоёв) — наша IP и доступна только в managed-версии.

⚠️
В open-source ядре нет промптов Anthropic Claude, ключей моделей или методологии Founder OS Score. Это сделано осознанно — чтобы IP не утекал в форки. Запуск ядра без managed-облака даёт пустой founder_score-tool.

Быстрый старт за 60 секунд

# 1. Клон
# URL появится после публичного релиза (Q3 2026)
# Подписаться на релиз: /developer/open-source.html#waitlist
git clone https://github.com/edl-os/mcp-server-core.git
cd mcp-server-core

# 2. Запуск через docker-compose
docker compose up -d

# 3. Проверка
curl http://localhost:8080/mcp/v1/health
# → {"status":"ok","version":"0.1.0","tools":6}
