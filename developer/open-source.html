Open Source ядро EDL OS

MCP-server core EDL OS будет опубликован под лицензией MIT после стабилизации публичного API. Эта страница — единственный источник правды о том, что войдёт в релиз, когда и как получить ранний доступ.

ℹ️
Зачем эта страница, если репо ещё нет? Мы строим EDL OS прозрачно. Ранние подписчики получают доступ к private alpha-репо за 2 месяца до публичного релиза — чтобы успеть собрать коннекторы под свой стек и повлиять на API.

Подписаться на релиз

Оставьте email — пришлём приглашение в private alpha за 2 месяца до публичного релиза (без спама, ~1 письмо в месяц со статусом).

Альтернатива: подпишитесь на Telegram-канал — релиз там же.

Что войдёт в open-source ядро

EDL OS использует подход Open Core — ядро открыто, бизнес-логика закрыта. Граница проходит так:

МодульРелизЛицензия
MCP-транспорт (JSON-RPC, SSE/HTTP)v1.0MIT
Tool registry & dispatcherv1.0MIT
OAuth 2.1 + PKCE handshakev1.0MIT
Audit log & per-tool rate limiterv1.0MIT
SDK для написания коннекторов (TypeScript)v1.0MIT
Docker Compose · helm chartv1.0MIT
Шаблоны конфигов Claude / Cursor / ChatGPT / Geminiv1.0MIT
Промпты Founder OS Score—Closed · managed cloud
Бенчмарки 100+ компаний—Closed · managed cloud
Методология Founder OS · 4 слоя—Closed · managed cloud
⚠️
Что НЕ войдёт: промпты Claude, ключи API моделей, бенчмарки компаний и промпт-формула Founder OS Score. Это сделано осознанно — open-source ядро остаётся «пустым каркасом» без managed cloud. Это защита от форков, которые присвоят методологию.

Коннекторы — что войдёт в репо

Все коннекторы публикуются вместе с ядром под MIT. Сейчас они в private alpha и итерируются с пилотными клиентами.

🏢

1С

УТ, ERP, Бухгалтерия. Подключение через HTTP-сервис в БД или COM. Возвращает выручку, маржу, поставщиков. PII фильтруется на стороне коннектора.

private alpha
💼

amoCRM

Сделки, контакты, пайплайны, события. OAuth 2.0 + webhooks для real-time. Hot-deals, конверсия по этапам, среднее время касания.

private alpha
🟦

Битрикс24

CRM + задачи + документы. Установка как локального приложения Bitrix24 + REST API. Сделки, задачи, нагрузка по сотрудникам.

private alpha
🎓

GetCourse

Заказы, пользователи, прогресс по курсам. API-токен + webhook на оплату. LTV, прогноз churn по неактивным.

private alpha
