Подключайте любого AI-агента

MCP — открытый протокол. EDL OS работает с каждым совместимым клиентом. Выберите свой.

Claude Desktop

официально · 1-click

Самый простой путь — кнопка «Установить» в hero. Альтернативно — отредактируйте конфиг вручную.

  1. Откройте Settings → Developer → Edit Config.
  2. Вставьте блок ниже в claude_desktop_config.json.
  3. Перезапустите Claude Desktop · OAuth откроется автоматически.
{
  "mcpServers": {
    "edl-os": {
      "url": "https://mcp.edl-os.com/v1",
      "transport": "sse"
    }
  }
}

Cursor

официально · MCP native

Откройте Cursor Settings · MCP · Add new MCP server. Или вставьте YAML ниже в ~/.cursor/mcp.json.

  1. Cmd/Ctrl + Shift + J → раздел MCP.
  2. Add new MCP server → URL: https://mcp.edl-os.com/v1.
  3. Cursor сам поднимет OAuth-окно при первом вызове tool.
{
  "mcpServers": {
    "edl-os": {
      "url": "https://mcp.edl-os.com/v1"
    }
  }
}

ChatGPT Desktop

через connector · бета

ChatGPT поддерживает MCP через коннекторы для Plus/Pro/Team. Добавьте EDL OS как Custom Connector.

  1. Settings → Connectors → Add Custom Connector.
  2. URL: https://mcp.edl-os.com/v1 · Auth: OAuth.
  3. Разрешите доступ — инструменты EDL OS появятся в новом чате.
# Connector URL
https://mcp.edl-os.com/v1

# Auth
OAuth 2.1 (PKCE)

Gemini CLI

через connector · бета

Gemini CLI v0.4+ поддерживает MCP. Добавьте сервер в ~/.gemini/settings.json.

  1. Установите Gemini CLI: npm i -g @google/gemini-cli.
  2. Добавьте блок ниже в ~/.gemini/settings.json.
  3. Запустите gemini mcp login edl-os для OAuth.
{
  "mcpServers": {
    "edl-os": {
      "httpUrl": "https://mcp.edl-os.com/v1",
      "auth": "oauth"
    }
  }
}
