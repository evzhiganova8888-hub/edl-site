Подключение

Bring Your Own Agent

Выберите свой ИИ-клиент и следуйте инструкции. Конфиг копируется в один клик.

1
Откройте Claude Desktop → Settings → Developer → Edit Config
2
Вставьте блок в claude_desktop_config.json: 
{
  "mcpServers": {
    "edl-os": {
      "command": "uvx",
      "args": ["mcp-server-core"],
      "env": {
        "EDL_OS_API_URL": "https://api.edl-os.ru/mcp/v1"
      }
    }
  }
}
3
Перезапустите Claude Desktop. Напишите: «Начни Founder OS Score». Claude задаст 12 вопросов и выдаст Score 0–100 с рекомендациями.
1
Откройте Cursor → Settings → MCP Servers → Add Server
2
Укажите: Name = edl-os, Command = uvx mcp-server-core
Или добавьте в ~/.cursor/mcp.json: 
{
  "mcpServers": {
    "edl-os": {
      "command": "uvx",
      "args": ["mcp-server-core"],
      "env": {
        "EDL_OS_API_URL": "https://api.edl-os.ru/mcp/v1"
      }
    }
  }
}
3
Перезапустите Cursor. В чате Agent Mode напишите: «Запусти Founder OS Score».
1
Откройте ChatGPT Desktop → Settings → Beta → MCP Servers
2
Нажмите "Add Server" и вставьте URL: 
https://api.edl-os.ru/mcp/v1
3
Авторизуйтесь через OAuth 2.1. Напишите: «Founder OS Score — начинаем».
1
Установите Gemini CLI: npm install -g @google/gemini-cli
2
Добавьте MCP-сервер в конфиг ~/.gemini/settings.json: 
{
  "mcpServers": {
    "edl-os": {
      "command": "uvx",
      "args": ["mcp-server-core"],
      "env": {
        "EDL_OS_API_URL": "https://api.edl-os.ru/mcp/v1"
      }
    }
  }
}
3
Запустите gemini и напишите: «Founder OS Score».
